# Next Chat Handoff — Montage Maker

## Current State

Fully functional NiceGUI desktop GUI (`app.py`) wrapping the `montage_maker.py` CLI engine. Runs as a native pywebview window (no browser needed). Three-column layout with themes, effects, and a curated preset set.

**Work completed across sessions:**
- Core NiceGUI GUI with 3-column layout (folders/generate/preview, settings, effects)
- Preset manager dialog (create/edit/delete presets in `config.ini`)
- Full effects support: drop shadow, frame, border, polaroid (with random angle)
- Theme system: Light, Warm, Dark, Midnight — saved in `session.ini [ui]`
- 11 bundled presets: Contact Sheet, Filmstrip, Gallery Wall, Instagram Post, Instagram Story, Link Preview, Pinterest Pin, Polaroid, Square 3×3, X Post, YouTube Thumb
- Overwrite vs auto-increment conflict dialog (overwrite targets most recent version only)
- Output image preview via FastAPI `/output-image` endpoint (cache-buster for overwrite)
- Shadow + Polaroid conflict fix: shadow disabled in UI and skipped in engine when polaroid active
- Persistent state via `session.ini`: input/output paths, server port, theme
- **Image selection panel**: collapsible "Input Image Files" above Generate button — checkboxes with 40×40 thumbnails, All/None buttons, "N of M selected" count; `generate()` passes only checked files to engine; auto-refreshes on folder change
- **Font selector**: `ui.select` with `with_input=True` populated from `magick -list font`; supports type-to-filter and custom entries
- **Text controls**: separate Title size + Label size (independent via two-pass rendering); Text color picker
- **Two-pass title rendering**: `montage` handles tiles/labels; `magick` splices and annotates title independently for separate size/color control
- **`_ensure_default_config()`**: auto-creates `config.ini` from `_DEFAULT_PRESETS` on first run (enables standalone exe)
- **`SCRIPT_DIR` fix**: resolves to exe directory in frozen builds via `sys.executable` path
- **`build.py`**: cross-platform PyInstaller build script; `nicegui-pack` broken on Windows
- **`_open_folder` Windows fix**: daemon thread + `os.startfile` + `keybd_event` trick → Explorer comes to foreground
- **Filmstrip preset**: added `border: 12x30`, `bordercolor: #000000` for film-proportioned frame lines; `title: Filmstrip`, `font: Arial`, `textcolor: #ffffff`
- **Contact Sheet preset**: added `title: Contact Sheet`
- **Column scaling**: removed `max-w-6xl` cap; flex ratios scale with window width

## How to Run

```
# Development
venv_win\Scripts\python app.py

# Build standalone exe (cross-platform) — tested on Windows
venv_win\Scripts\python build.py      # Windows
venv_mac/bin/python build.py          # macOS

# CLI (original, still works)
venv_win\Scripts\python montage_maker.py 2x2
venv_win\Scripts\python montage_maker.py --preset "Instagram Post"
```

**Kill the process if Ctrl+C doesn't respond:** `taskkill /F /IM python.exe` in a second terminal.

## Gotchas for Next Session

- **Folder browser**: Uses `tkinter.filedialog`, NOT `app.native.main_window` (pywebview dialog is broken in this NiceGUI/pywebview version combo)
- **Preset apply**: Always uses `.get(key, default)` for ALL fields — don't revert to `if key in pc` pattern (causes stale values from previous preset to persist)
- **Auto-increment**: Never write the incremented prefix back to `prefix_in` — causes compounding on repeat runs
- **ConfigParser**: `dict(config[section])` includes DEFAULT section keys — always filter with `inherited = set(config.defaults())`
- **Output image display**: Always use `/output-image?p={quote(path)}&t={timestamp}` — never `ui.image(path)` directly. NiceGUI's deterministic URL for the same file path causes WebView2 to serve the cached old image on overwrite.
- **Shadow + Polaroid**: Never pass `-shadow` when `polaroid` is set (they conflict at the ImageMagick level). Shadow switch should be bound disabled from polaroid switch in any new UI that adds both controls.
- **Title rendering**: Two-pass only. `montage` does NOT reliably apply `-pointsize`/`-fill` set before `-title`. Pass 1 = `montage` without title; pass 2 = `magick <output> -splice -annotate title`. Never put `-title` back into the `montage` command.
- **`magick` not `convert`**: On Windows IM7, `convert.exe` is the Windows system file converter. Use `["magick", ...]` for all non-`montage` IM calls.
- **Image selection checkbox closure**: Always use the `make_handler(name)` factory pattern inside the loop — never a plain lambda that captures `fname`.
- **`_FONTS` population**: `_load_imagemagick_fonts()` is called at module level; if IM is not on PATH it returns `[]` and both font selects fall back to empty (still usable as free-text).
- **`_ensure_default_config()` is one-shot**: existing `config.ini` is never overwritten. To pick up new preset defaults, delete config.ini (regenerates on next launch) or update presets via Manage….
